# 주요업무추진계획 자동화 · 20일 수합 상세 기획

- 노션 원문: [주요업무추진계획(구청&재단/20일제출)자동화](https://app.notion.com/p/3a891b75d56c80caa937d2816274b56a)

## 1. 업무 정의

개별관이 매월 20일까지 주요 업무 추진 계획을 한 번 입력한다. 수합 관리자는 동일 원천 데이터를 검토·정제하여 구청용 상세 추진계획과 재단용 월간일정표를 각각 생성한다.

## 2. 핵심 원칙

- 개별관은 구청용과 재단용 자료를 이중 작성하지 않는다.
- 원천 데이터는 하나이고 기관별 포함 여부, 제목, 순서, 출력 형식만 분리한다.
- 구청용은 상세정보를 유지하고 재단용은 일정표에 필요한 필드만 추출한다.
- 자동 축약·자동 중복 삭제로 확정하지 않고 수합 관리자가 최종 판단한다.

## 3. 공통 데이터

핵심항목은 도서관, 대상 월, 사업·행사명, 개요·주요 내용, 일시 또는 운영기간, 장소, 대상, 담당자다.

선택·관리항목은 담당자 직급·연락처, 접수기간·방법, 강사·진행자, 회차별 일정, 예산, 홍보·향후계획, 사업 구분, 기관별 출력 여부와 순서, 제목 축약값, 검토 메모다.

## 4. 기관별 변환

| 원천 데이터 | 구청용 | 재단용 |
|---|---|---|
| 도서관 | 관별 구분 유지 | 행사명 앞 관 약칭 |
| 행사명 | 원문 중심 | 의미를 유지한 축약값 |
| 개요·세부내용 | 상세 반영 | 제외 |
| 일시 | 상세 형식 | 일정표 일시 열 |
| 장소 | 반영 | 장소 열 |
| 대상 | 반영 | 제외 |
| 담당자 | 양식에 맞는 상세정보 | 이름만 |
| 연번 | 관별 구조 | 최종 포함 행 기준 재부여 |

재단용은 일시, 내용, 장소, 담당자만 추출하고 `[노중]`, `[월계]`, `[상계]`, `[불암]` 등 관 약칭을 적용한다. 복수 회차는 한 행 통합 또는 회차별 분리를 관리자가 선택한다.

## 5. 검증

- 날짜·요일 일치
- 시작일과 종료일 순서
- 대상 월 외 일정 경고
- 장소·담당자 누락
- 동일 관·유사 제목·유사 기간 중복 후보
- 기관별 필수항목
- 제목 원문과 축약값 동시 보존

## 6. 구청용 출력 계약

- A4 세로, 좌우 16mm, 위 15mm, 아래 10mm
- 표가 아닌 문단형 문서
- 제목: 신명 견고딕 20pt, 가운데, 줄간격 170%
- 사업 제목: 신명 견고딕 14pt, 굵게, 줄간격 170%
- 상세항목: 신명 태명조 14pt, 줄간격 170%
- 항목 기호: `○ 개요`, `○ 일시`, `○ 장소`, `○ 대상`, `○ 담당자`
- 제목 형식: `연번. [사업 구분] 사업·행사명 (도서관명)`
- 도서관명은 탭 정렬하고 긴 제목은 내어쓰기한다.
- 제목과 첫 상세항목은 같은 페이지에 유지한다.

## 7. 재단용 출력 계약

- A4 세로, 좌우 10mm, 위·아래 5mm
- 5열: 연번 14.9mm, 일시 39.8mm, 내용 75.6mm, 장소 37.8mm, 담당자 20.9mm
- 제목: HY헤드라인M 20pt
- 부서명: HY견고딕 13pt, 기울임
- 열 제목: HY견고딕 12pt
- 데이터: 굴림 12pt, 가로·세로 가운데, 줄간격 100%
- 내용이 길어도 열 너비는 유지하고 행 높이만 확장한다.
- 다음 페이지에서 열 제목을 반복한다.

## 8. 출력 검증

- 구청용 글꼴·줄간격·내어쓰기·도서관명 정렬
- 재단용 5개 열 너비와 데이터 정렬
- 관 약칭, 제목 축약, 담당자 이름, 연번
- 중복 제외와 복수 회차 처리 결과
- 양식 안내 문구 제거
