# 주요업무현황보고 자동화 · 10일 수합 상세 기획

> 2026-08-08 변경: 입력은 매월 10일 16:00 마감의 통합 수합 1회로 전환됨. 이 문서는 구청 현황보고 출력 계약으로 유지함.

- 노션 원문: [주요업무현황보고(구청/10일제출)자동화](https://app.notion.com/p/3a891b75d56c80578832d6383acc9691)

## 1. 업무 정의

개별관이 통합 수합에 한 번 입력한 문화프로그램 자료를 원천으로 사용한다. 수합 관리자는 주요 행사를 선별·정렬한 뒤 구청 제출용 통합 HWPX를 생성한다.

## 2. 입출력

| 항목 | 내용 |
|---|---|
| 입력 주체 | 개별관 수합 담당자 |
| 입력 자료 | 관별 주요 업무 현황 보고 |
| 최종 결과 | 노원구립도서관 통합 주요 업무 현황 보고 |
| 제출처 | 구청 |

## 3. 데이터 항목

필수항목은 도서관, 보고 대상 월, 사업·행사명, 일시, 장소, 대상, 주요 내용이다.

선택·관리항목은 강사·진행자, 접수기간·방법, 예산, 홍보·향후계획, 회차별 세부내용, 사업 구분, 최종 반영 여부, 출력 순서, 관리자 메모다.

일정은 원문과 정규화한 시작·종료일시를 함께 저장한다. 유형은 단일, 기간, 반복, 복수 회차로 구분한다.

사진 파일과 이미지 상태는 시스템 데이터로 수집하지 않는다. 사진은 관별 Google Drive 폴더로 별도 수령한다.

운영 데이터는 Google Sheets에 저장하고 Apps Script Web App을 통해
읽고 쓴다. 브라우저는 Netlify Function을 거쳐 접근하며 계정 비밀번호와
서비스 간 비밀값은 시트에 평문으로 저장하지 않는다.

## 4. 업무 규칙

1. 구청 기존 양식을 유지한다.
2. 웹 입력자료를 최종 문서의 원천 데이터로 사용한다.
3. 날짜 원문과 정규화 값을 함께 보존한다.
4. 날짜·요일 불일치는 경고하고 시작일이 종료일보다 늦으면 제출을 차단한다.
5. 사진 제출 여부는 시스템 제출 조건에 포함하지 않고 Drive에서 별도로 확인한다.
6. 중복 후보는 표시하되 자동 제외하지 않는다.
7. 최종 반영 여부, 제외 사유, 관별·행사별 순서는 수합 관리자가 결정한다.
8. 마감 시각은 16:00이며 이후 제출도 허용하고 지연 제출로 표시한다.
9. 제출 후에는 잠그고 관리자 수정 요청이 있을 때만 제출자가 다시 수정한다.

## 5. 기능

### 제출자

- 관별 복수 행사 등록
- 행사 복제·삭제·순서 변경
- 임시저장·제출·재제출
- 사진 별도 제출 방식과 Drive 위치 안내
- 오류 위치 안내

### 수합 관리자

- 관별 제출·미제출·수정요청 현황
- 필수값·날짜·요일 오류 필터
- 행사 포함·제외, 제외 사유, 검토 메모
- 관별·행사별 출력 순서
- 통합 결과 미리보기와 HWPX 생성

## 6. 출력 계약

- A4 세로
- 여백: 좌우 20mm, 위 18mm, 아래 14mm, 머리말·꼬리말 10mm
- 상단 제목표: 번호 약 12.9mm, 제목 약 148.1mm
- 본문 3열: 구분 16.7mm, 내용 115.7mm, 이미지 38.8mm
- 번호·제목: HY견고딕 17pt, 줄간격 160%
- 현안사항 구분명: 맑은 고딕 13pt, 가운데
- 추진 개요·사업내용: 맑은 고딕 13pt, 양쪽, 줄간격 160%
- 행사 제목: 맑은 고딕 13pt, 굵게, 검정색
- 일시·장소·대상·내용과 일반 세부내용: 맑은 고딕 12pt, 검정색, 줄간격 160%
- 모든 텍스트는 검정색으로 출력
- 이미지 열 너비를 고정하고 자동 생성본에는 빈 삽입 영역만 유지

## 7. 출력 검증

- 행사별 이미지 삽입 영역이 누락되지 않고 비어 있는지 확인한다.
- 검토자는 이미지 제외 HWPX의 텍스트 검수를 마친 뒤 Drive 사진을 직접 삽입한다.
- 긴 내용이 잘리거나 표·페이지 밖으로 나가지 않는지 확인한다.
- 열 너비와 표 전체 폭이 변하지 않았는지 확인한다.
- 양식 안내 문구와 내부 메모가 남지 않았는지 확인한다.
