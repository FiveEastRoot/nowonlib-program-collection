# PRD · 주요업무추진계획 자동화 · 20일 수합

- 상태: Draft v0.1
- 개발 목표일: 2026-08-01
- 검증 목표: 2026-08-20
- 노션 원문: [PRD_주요업무추진계획 자동화_20일 수합](https://app.notion.com/p/3a891b75d56c81a0af1ff52deca102fa)

## 1. 제품 목표

개별관이 추진계획을 한 번만 입력하고 수합 관리자가 공통 데이터를 확정한다. 시스템은 구청용 상세 추진계획과 재단용 월간일정표를 독립적으로 생성한다.

비목표는 임의 제목 확정, 중복 자동 삭제, 외부기관 양식 변경, 기관별 이중 입력이다.

## 2. 사용자

| 역할 | 권한 |
|---|---|
| 개별관 제출자 | 본인 관 추진계획 등록·임시저장·제출·수정·재제출 |
| 수합 관리자 | 전체 검토, 수정 요청, 공통 데이터 확정, 기관별 포함·제외·축약·중복·정렬, 미리보기와 생성 |

수합 담당자와 검토자는 동일인이다.

## 3. 상태

`작성중 → 제출완료 → 수정요청 → 재제출완료 → 공통검토완료 → 기관별설정중 → 출력대기 → 출력완료 → 마감완료`

수정 요청이 없으면 `제출완료 → 공통검토완료`로 진행한다.

## 4. 데이터 모델

- 수합 회차
- 관별 제출
- 추진계획 항목
- 일정
- 기관별 출력 설정
- 중복 그룹
- 관리자 처리 기록
- 출력 작업
- 감사 로그

## 5. 핵심 요구사항

### 공통 입력·검토

- `FR-20-001` 한 번 입력한 원천 데이터를 구청·재단에 사용
- `FR-20-002` 복수 사업·복수 회차
- `FR-20-003` 제출·수정·재제출 이력
- `FR-20-004` 원문과 정규화 값 비교

### 검증

- `FR-20-010` 날짜·요일 불일치 경고
- `FR-20-011` 역전 기간 차단
- `FR-20-012` 대상 월 밖 일정 경고
- `FR-20-013` 기관별 장소·담당자 검증
- `FR-20-014` 중복 후보 표시

### 구청 출력

- `FR-20-020` 상세항목 유지
- `FR-20-021` 관별·사업별 순서
- `FR-20-022` 긴 제목 내어쓰기
- `FR-20-023` 제목과 첫 상세항목 같은 페이지 유지

### 재단 출력

- `FR-20-030` 일시·내용·장소·담당자 추출
- `FR-20-031` 관 약칭 자동값과 수동 수정
- `FR-20-032` 제목 축약값 편집
- `FR-20-033` 담당자 이름 추출
- `FR-20-034` 중복 제외 후 연번 재부여
- `FR-20-035` 복수 회차 통합·분리 선택

### 출력 작업

- `FR-20-040` 구청·재단 독립 미리보기와 생성
- `FR-20-041` 한 출력 실패가 다른 출력을 훼손하지 않음
- `FR-20-042` 실패 원인과 재시도

## 6. 비기능 요구사항

- 두 결과물이 동일 원천 데이터와 연결된다.
- 제목 원문과 축약값을 모두 보존한다.
- 기관별 설정 변경을 감사 로그로 기록한다.
- 일반 목록과 미리보기는 3초 이내 표시한다.
- 구청·재단 출력은 독립 상태와 오류를 가진다.
- 최신 Chrome·Edge를 우선 지원한다.

## 7. 수용 기준

- 개별관은 한 번만 입력한다.
- 관리자는 구청·재단 포함 여부를 따로 설정한다.
- 구청 결과는 상세정보와 관별 구조를 유지한다.
- 재단 결과는 일시·내용·장소·담당자를 정확히 매핑한다.
- 관 약칭, 축약, 담당자 이름, 중복 제외, 연번 재부여가 반영된다.
- 날짜·요일·기간 오류가 출력 전에 표시된다.
- 한 출력 실패가 다른 출력 상태를 훼손하지 않는다.
- 긴 텍스트가 열 너비를 바꾸거나 페이지 밖으로 나가지 않는다.
