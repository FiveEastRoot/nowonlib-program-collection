## 개발 순서

1. 공통 데이터 모델, 회차, 권한
2. 제출자 입력·임시저장·제출·재제출
3. 관리자 현황·검토·정렬
4. 공통 검증
5. 10일 HWPX 출력
6. 20일 구청·재단 출력
7. 과거 HWP 표본 기반 회귀 테스트
8. 8월 실제 수합 검증과 안정화
