# PRD · 주요업무현황보고 자동화 · 10일 수합

- 상태: Draft v0.1
- 개발 목표일: 2026-08-01
- 최초 운영: 2026-08-10
- 노션 원문: [PRD_주요업무현황보고 자동화_10일 수합](https://app.notion.com/p/3a891b75d56c81808416fa9b7674e3d5)

## 1. 제품 목표

관별 자료의 표현과 날짜를 표준화하고, 수합 관리자가 관별 현황과 오류를 확인하여 최종 포함 행사와 순서를 확정한 뒤 기존 3열 HWPX 보고서를 생성한다.

비목표는 구청 양식 변경, 모든 비정형 중첩표의 완전 자동 재현, Drive 사진의 자동 수집·삽입, 관리자 판단의 자동 대체다.

## 2. 사용자

| 역할 | 권한 |
|---|---|
| 개별관 제출자 | 본인 관 자료 등록, 임시저장, 제출, 마감 전 수정, 재제출 |
| 수합 관리자 | 전체 조회, 오류 확인, 수정 요청, 검토, 포함·제외, 정렬, 미리보기 검수, 결과 생성 |

수합 담당자와 검토자는 동일인이다.

## 3. 상태

`작성중 → 제출완료 → 수정요청 → 재제출완료 → 검토완료 → 출력대기 → 출력완료 → 마감완료`

수정 요청이 없으면 `제출완료 → 검토완료`로 진행한다.

## 5. 핵심 요구사항

### 제출·수정

- `FR-10-001` 관별 복수 행사
- `FR-10-002` 행사 복제·순서 변경·임시저장·삭제
- `FR-10-003` 마감 전 또는 수정 요청 시 제출 후 수정
- `FR-10-004` 제출·수정·재제출 사용자와 시각 기록

### 검증

- `FR-10-010` 필수항목 누락 시 제출 차단
- `FR-10-011` 날짜·요일 불일치 경고
- `FR-10-012` 시작일이 종료일보다 늦으면 차단
- `FR-10-013` 사진 제출 여부와 관계없이 텍스트 자료를 제출할 수 있음
- `FR-10-014` 동일 관·유사 제목·유사 기간 중복 후보 표시

### 관리자

- `FR-10-020` 행사별 포함·제외
- `FR-10-021` 제외 사유
- `FR-10-022` 관별·행사별 출력 순서
- `FR-10-023` 관별 제출 상태와 오류 집계

### 출력

- `FR-10-030` 포함 행사만 출력
- `FR-10-031` 기존 3열 템플릿과 순서 유지
- `FR-10-032` 기존 이미지 열에 빈 삽입 영역을 유지하고 이미지는 자동 삽입하지 않음
- `FR-10-033` 열 너비 고정, 행 높이 확장
- `FR-10-034` 생성 실패 원인과 재시도

## 6. 비기능 요구사항

- 저장 데이터의 지속성
- 주요 변경 감사 로그
- 일반 목록 3초 이내 표시
- 출력 중 중복 실행 방지
- 최신 Chrome·Edge 우선 지원
- 개인정보는 권한 사용자에게만 표시

## 7. 수용 기준

- 필수값 누락 제출 차단과 날짜·요일 경고가 동작한다.
- 관리자가 포함·제외와 순서를 바꿀 수 있다.
- 확정된 행사만 결과에 포함된다.
- 일반 세부내용은 맑은 고딕 12pt, 모든 텍스트는 검정색이다.
- 모든 출력 행사에 검토자가 사진을 붙일 수 있는 빈 이미지 영역이 유지된다.
- 긴 텍스트가 잘리거나 표 밖으로 나가지 않는다.
- 안내 문구와 내부 메모가 제거된다.
