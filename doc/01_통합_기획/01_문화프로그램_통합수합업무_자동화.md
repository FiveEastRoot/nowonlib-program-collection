# 문화프로그램 통합수합업무 자동화

- 상태: 진행중
- 목표일: 2026-08-01
- 최초 운영: 2026-08-10 수합
- 노션 원문: [문화프로그램_통합수합업무 자동화](https://app.notion.com/p/3a891b75d56c808cb19cd751b015aa7b)

## 1. 목표

개별관은 문화프로그램 자료를 매월 한 번 웹 시스템에 표준화하여 입력한다. 마감은 매월 10일 16:00이며, 수합 관리자는 같은 검토완료 원천자료로 외부기관별 기존 양식 3종을 생성한다.

## 2. 개발 대상

| 구분 | 입력 자료 | 최종 결과 | 제출처 |
|---|---|---|---|
| 매월 10일 통합 수합 | 문화프로그램 공통 원천자료 | 통합 주요 업무 현황 보고 | 구청 |
| 동일 원천자료 | 문화프로그램 공통 원천자료 | 주요 업무 추진 계획 | 구청 |
| 동일 원천자료 | 문화프로그램 공통 원천자료 | 월간일정표 | 재단 |

## 3. 공통 개발 범위

- 사용자 인증과 관별 권한
- Google Sheets 운영 데이터 저장과 Apps Script Web App 연계
- 수합 업무 구분, 대상 월, 회차와 마감 관리
- 관별 복수 사업·행사 등록
- 단일·기간·반복·복수 회차 일정 표준화
- 임시저장, 제출, 수정 요청, 재제출
- 날짜·요일·기간·필수값·중복 후보 검증
- 사진은 Google Drive로 별도 수령하고 시스템은 텍스트 데이터만 수합
- 관별 제출·미제출·오류 현황
- 관리자 검토, 포함·제외, 출력 순서, 메모
- 문서별 HWPX 템플릿과 독립적인 출력 작업
- 감사 로그와 오류 기록

## 6. 완료 기준

- 같은 시스템에서 월별 통합 수합 회차 1개를 관리한다.
- 개별관 담당자가 사업·행사를 등록·수정·제출·재제출할 수 있다.
- 필수값, 날짜·요일, 기간 오류가 제출 전에 검증된다.
- 관리자가 관별 제출 상태, 포함 여부, 출력 순서를 관리한다.
- 같은 검토완료 원천자료로 구청 현황보고·구청 추진계획·재단 월간일정표를 생성한다.
- 줄바꿈, 특수문자, 날짜 원문, 기간, 복수 회차 정보가 출력에서 손상되지 않는다.
- 제출자와 관리자가 제출 완료 여부를 명확히 확인한다.

## 7. 1차 운영 원칙

- 외부기관의 확정 HWPX 양식을 유지하며 HWP는 사용하지 않는다.
- 텍스트 데이터의 수집·정제·재배치를 우선 자동화한다.
- 사진은 별도 Google Drive 폴더로 수령하며 시스템 데이터와 연결하거나 업로드하지 않는다.
- 시스템은 이미지가 들어갈 영역을 비워 둔 HWPX를 생성하고, 수합 검토자가 Drive 사진을 확인해 최종 문서에 직접 삽입한다.
- 시스템 장애 시에도 HWP를 사용하지 않고 시트 임시입력·HWPX 수동 생성 절차로 대응한다.
- 신규 안내에는 입력 링크, 사진 제출용 Drive 링크, 마감 시각, 필수항목, 수정·재제출, 완료 확인, 문의 방법을 포함한다.

## 8. 결과 문서 원칙

- 공통 데이터 구조를 사용하되 문서별 전용 HWPX 템플릿으로 생성한다.
- 확정된 HWPX 템플릿의 XML을 Google Sheets 확정 데이터로 치환한다.
- HWPX 생성은 Netlify Function에서 수행하고 생성 이력과 Drive 파일 정보는 Apps Script를 통해 기록한다.
- 10일 현황보고는 이미지 삽입 영역을 유지한 3열 표이며 자동 생성 시 이미지는 비워 둔다.
- 20일 구청 추진계획은 문단형 상세 문서다.
- 20일 재단 월간일정표는 5열 표다.
- 글꼴, 크기, 정렬, 줄간격, 열 너비, 관별 순서, 여백을 자동 적용한다.
- 내용 길이에 따라 높이는 확장하되 열 너비와 기본 서식은 바꾸지 않는다.
- 양식의 작성 안내 문구와 내부 메모는 결과물에서 제거한다.

## 9. 운영 데이터·연계 원칙

- Google Sheets를 운영 데이터의 기준 저장소로 사용한다.
- Apps Script Web App은 Google Sheets 읽기·쓰기와 Google Drive 파일 연계를 담당한다.
- 브라우저는 Apps Script를 직접 호출하지 않고 Netlify Function을 통한다.
- Netlify Function은 공용 제출 계정·관리자 세션, 권한, 요청 검증과 HWPX 생성을 담당한다.
- 계정 비밀번호는 시트에 평문으로 저장하지 않고 해시 또는 배포 환경변수로 관리한다.
- Netlify와 Apps Script 사이의 비밀값은 Netlify 환경변수와 Apps Script Script Properties에 저장한다.
- 동일 제출자료의 동시 수정은 Apps Script 잠금으로 보호한다.
- 주요 저장·제출·수정요청·재제출·문서 생성은 감사 로그에 기록한다.
- Apps Script 장애 또는 할당량 초과 시 요청은 실패 상태로 남기고 관리자가 재시도할 수 있어야 한다.
