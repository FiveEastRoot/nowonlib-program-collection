## 확정된 공통 원칙

- 월별 수합은 매월 10일 16:00 마감의 통합 수합 1회로 운영한다.
- 한 번 입력·검토한 원천자료에서 구청 현황보고, 구청 추진계획, 재단 월간일정표 HWPX 3종을 생성한다.
- 기존 10일·20일 회차는 과거 기록 조회 호환을 위해 보존한다.
- 사용자 역할은 `개별관 제출자`와 `수합 관리자` 두 가지다.
- 수합 담당자와 검토자는 동일인이고 별도 이중 승인 단계는 두지 않는다.
- 외부기관의 확정 HWPX 양식을 변경하지 않으며 HWP는 사용하지 않는다.
- 원문과 정규화 값을 함께 보존하고, 포함·제외·축약·중복 처리의 최종 판단은 수합 관리자가 한다.
- 운영 데이터 저장소는 Google Sheets, 시트·Drive 연계 API는 Apps Script Web App으로 사용한다.
- 브라우저는 Apps Script를 직접 호출하지 않고 Netlify Function을 통해 인증·요청 검증 후 접근한다.
- 계정 비밀번호와 서비스 간 비밀값은 Google Sheets에 평문으로 저장하지 않는다.
- 동시 저장은 Apps Script 잠금으로 보호하고 모든 주요 변경은 감사 로그에 남긴다.
- 사진은 Google Drive로 별도 수령하며 앱·DB·HWPX 생성 데이터에 포함하지 않는다.
- 자동 생성 HWPX에는 이미지 삽입 영역만 남기고, 검토자가 텍스트 검수 후 사진을 직접 삽입한다.
