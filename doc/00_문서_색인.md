## 확정된 공통 원칙

- 10일 수합과 20일 수합은 마감일과 출력물이 다른 별도 프로세스다.
- 데이터 저장, 제출 상태, 검증, 관리자 검토, 정렬, 출력 작업은 공통 플랫폼으로 개발한다.
- 10일·20일 모듈은 유사한 처리 구조를 공유하므로 2026-08-01 1차 목표를 향해 동시에 개발한다.
- 사용자 역할은 `개별관 제출자`와 `수합 관리자` 두 가지다.
- 수합 담당자와 검토자는 동일인이고 별도 이중 승인 단계는 두지 않는다.
- 외부기관의 기존 HWP·HWPX 양식은 변경하지 않는다.
- 원문과 정규화 값을 함께 보존하고, 포함·제외·축약·중복 처리의 최종 판단은 수합 관리자가 한다.
- 사진은 Google Drive로 별도 수령하며 앱·DB·HWPX 생성 데이터에 포함하지 않는다.
- 자동 생성 HWPX에는 이미지 삽입 영역만 남기고, 검토자가 텍스트 검수 후 사진을 직접 삽입한다.
